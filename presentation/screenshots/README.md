# لقطات الشاشة للعرض التقديمي

ضع في هذا المجلد لقطات الشاشة بالأسماء التالية حتى تظهر في الملف `index.html`:

| اسم الملف | الوصف — ما تصوره |
|-----------|-------------------|
| `01-home.png` | الصفحة الرئيسية للمتجر (السلايدر + التصنيفات أو المنتجات المميزة) |
| `02-categories.png` | صفحة أحد التصنيفات تعرض شبكة المنتجات مع الفلاتر والترتيب |
| `03-product.png` | صفحة تفاصيل منتج واحد (معرض الصور، السعر، المتغيرات، التقييمات) |
| `04-cart.png` | صفحة السلة أو صفحة إتمام الطلب (Checkout) |
| `05-account.png` | لوحة حساب المستخدم (طلباتي أو عناويني أو تبويب الرئيسية) |
| `06-admin-dashboard.png` | لوحة تحكم الإدارة — الصفحة الرئيسية مع الـ widgets |
| `07-admin-orders.png` | قائمة الطلبات في لوحة التحكم (مع أعمدة الفرز والترقيم) |
| `08-admin-users.png` | قائمة المستخدمين في لوحة التحكم |
| `09-lang-theme.png` | أي صفحة من الموقع تظهر فيها لغة عربية وزر تبديل الثيم (فاتح/داكن) |

**ملاحظات:**
- الصيغ المدعومة: `png`, `jpg`, `jpeg`, `webp` — غيّر امتداد الملف في `index.html` إذا استخدمت غير PNG.
- المقاس المقترح: عرض حوالي 1200px ليكون واضحاً على الشاشة.
