عرض تقديمي — الوظائف والميزات

نظرة عامة على المشروع

المشروع مبني باستخدام Laravel 12 وهيكل موديولار (Nwidart Modules) مع طبقة خدمات. يدعم المتجر:

  • لغتان: العربية والإنجليزية (قيم قابلة للتعديل من لوحة التحكم)
  • ثيم: وضع فاتح ووضع داكن
  • تصنيفات ومنتجات مع صور متعددة ومتغيرات (مقاس/لون)
  • سلة شراء وطلبات مع دفع كاش أو تحويل بنكي
  • لوحة تحكم إدارية كاملة للطلبات والمنتجات والمستخدمين والإعدادات

الصفحة الرئيسية

لقطة شاشة: الصفحة الرئيسية — أضف الملف screenshots/01-home.png

المحتوى

  • سلايدر رئيسي — ثلاث صور قابلة للتعديل من الإعدادات
  • التصنيفات — عرض التصنيفات مع روابط للتصفح
  • منتجات مميزة — شبكة منتجات مع خصومات وعرض سريع
  • شهادات العملاء (Testimonials)
  • شريط إعلاني علوي وبانرات ترويجية قابلة للإدارة من لوحة التحكم

التصنيفات والمنتجات

لقطة: صفحة التصنيف — screenshots/02-categories.png

الوظائف

  • عرض المنتجات حسب التصنيف مع ترتيب وتصفية (السعر، التوفر، النطاق السعري)
  • بطاقة منتج تحتوي: صورة، اسم، سعر، خصم، زر عرض سريع، إضافة للسلة
  • خبز التنقل (Breadcrumbs) مع بيانات منظمة JSON-LD لمحركات البحث

صفحة المنتج

لقطة: صفحة تفاصيل المنتج — screenshots/03-product.png

الميزات

  • معرض صور متعدد مع إمكانية التبديل
  • متغيرات المنتج (مقاس، لون، إلخ) مع سعر ومخزون خاص بكل متغير
  • تقييمات العملاء مع تفصيل النجوم وشارة «شراء موثق»
  • منتجات ذات صلة وشوهدت مؤخراً
  • عرض سريع من شبكة المنتجات دون مغادرة الصفحة

السلة والدفع

لقطة: صفحة السلة — screenshots/04-cart.png

السلة

  • عرض العناصر مع الكمية والسعر والمتغير إن وجد
  • تحديث الكمية أو حذف الصنف

إتمام الطلب (Checkout)

  • نموذج عنوان الشحن والتفاصيل
  • اختيار طريقة الدفع: كاش أو تحويل بنكي
  • ملخص الطلب وشعارات الثقة (قابلة للتعديل من الإعدادات)

حساب المستخدم

لقطة: لوحة حساب المستخدم — screenshots/05-account.png

  • لوحة التحكم: ملخص الطلبات والنشاط
  • طلباتي: قائمة الطلبات مع التفاصيل والتتبع
  • عناويني: إدارة عناوين الشحن
  • السلة / المفضلة حسب التفعيل

لوحة التحكم — نظرة عامة

لقطة: لوحة التحكم الإدارية — screenshots/06-admin-dashboard.png

  • Widgets: طلبات اليوم، طلبات الأسبوع، مدفوعات بنكية معلقة، رسائل اتصل بنا غير مقروءة، منتجات منخفضة المخزون
  • قوائم جانبية للوصول السريع: الطلبات، المدفوعات، المنتجات، التصنيفات، المستخدمون، الرسائل، الإعدادات، المدونة، البانرات، الشهادات، المراجعات، إلخ.

لوحة التحكم — الجداول والفرز

لقطة: قائمة الطلبات مع فرز — screenshots/07-admin-orders.png

وظائف الجداول

  • ترقيم الصفحات مع اختيار عدد العناصر (10، 20، 50، 100) — افتراضي 20
  • الفرز (Sorting) بالنقر على عناوين الأعمدة (تصاعدي/تنازلي)
  • تصفية حسب الحالة، الرقم، إلخ. وتصدير الطلبات CSV
  • نفس النمط في: الطلبات، المنتجات، المستخدمون، الرسائل، المدفوعات، التصنيفات، المراجعات، المدونة، البانرات

لوحة التحكم — المستخدمون والإعدادات

لقطة: قائمة المستخدمين — screenshots/08-admin-users.png

المستخدمون

عرض جميع المستخدمين مع البحث والتصفية (عميل/مسؤول) والترقيم والفرز.

الإعدادات

  • معلومات الموقع والشعار واللغة والعناوين القابلة للتعديل
  • روابط التواصل: واتساب، إنستغرام، فيسبوك، البريد، الموقع، الهواتف
  • وضع الصيانة مع تاريخ العودة وقائمة IP المسموح لها
  • شعارات الثقة وكود مخصص (Header/Footer) لفريق الإعلام

اللغات والثيم

لقطة: تبديل اللغة والوضع الداكن — screenshots/09-lang-theme.png

  • العربية (ar) والإنجليزية (en) — تبديل من الواجهة مع حفظ التفضيل
  • نصوص القوائم والعناوين من ملفات الترجمة أو من الإعدادات (Labels)
  • وضع فاتح / وضع داكن — تبديل من الشريط مع دعم تلقائي لتفضيل النظام

ميزات إضافية

  • موافقة الكوكيز (Cookie consent) — شريط في الأسفل مع خيار القبول
  • شريط إعلاني علوي ونافذة منبثقة / إعلان قابلة للإغلاق
  • مدونة/أخبار — مقالات مع نشر مجدول
  • بانرات ترويجية — فترة عرض وتفعيل/إلغاء من لوحة التحكم
  • خريطة الموقع (Sitemap) — /sitemap.xml للمحركات
  • وضع الصيانة — صفحة «سنعود قريباً» مع قائمة IP للمشرفين
  • صفحات ثابتة — الشروط، الخصوصية، الشحن، المرتجعات (محتوى من الإعدادات)
