# العرض التقديمي — متجر Mood Abaya

عرض تقديمي باللغة العربية يشرح وظائف وميزات المتجر.

## كيف تعرض العرض التقديمي

1. افتح الملف **`index.html`** في متصفح (مزدوج النقر أو السحب إلى المتصفح).
2. تصفح الشرائح بالتمرير للأسفل أو طباعة إلى PDF من المتصفح (Ctrl+P → حفظ كـ PDF).

## إضافة لقطات الشاشة

1. شغّل المتجر محلياً (`php artisan serve` أو على السيرفر).
2. التقط لقطات للصفحات المطلوبة (أداة القص في Windows أو لقطة الشاشة في المتصفح).
3. احفظ الملفات في مجلد **`screenshots/`** بالأسماء التالية:

| الملف | الصفحة المطلوبة |
|-------|------------------|
| `01-home.png` | الصفحة الرئيسية |
| `02-categories.png` | صفحة تصنيف (قائمة المنتجات) |
| `03-product.png` | صفحة منتج واحد |
| `04-cart.png` | السلة أو إتمام الطلب |
| `05-account.png` | حساب المستخدم |
| `06-admin-dashboard.png` | لوحة التحكم (الصفحة الأولى) |
| `07-admin-orders.png` | قائمة الطلبات في الإدارة |
| `08-admin-users.png` | قائمة المستخدمين في الإدارة |
| `09-lang-theme.png` | أي صفحة تظهر فيها اللغة وزر الثيم |

تفاصيل إضافية في **`screenshots/README.md`**.

## المحتويات

- **الغلاف** — عنوان المتجر
- **نظرة عامة** — تقنية المشروع واللغات والثيم
- **الصفحة الرئيسية** — السلايدر، التصنيفات، المنتجات المميزة، الشهادات
- **التصنيفات والمنتجات** — الفلاتر، الترتيب، البطاقات
- **صفحة المنتج** — الصور، المتغيرات، التقييمات، العرض السريع
- **السلة والدفع** — السلة، إتمام الطلب، طرق الدفع
- **حساب المستخدم** — الطلبات، العناوين
- **لوحة التحكم** — الـ widgets، الجداول، الفرز، الترقيم
- **المستخدمون والإعدادات** — القوائم، الإعدادات، التواصل، الصيانة
- **اللغات والثيم** — العربية/الإنجليزية، فاتح/داكن
- **ميزات إضافية** — الكوكيز، المدونة، البانرات، Sitemap، الصيانة
