Mood Abaya Store

E-commerce for Abayas, Jilbabs & Hijabs

Presentation — Features & functionality

Project overview

Built with Laravel 12 and a modular structure (Nwidart Modules) with a service layer. The store supports:

  • Two languages: Arabic and English (values editable from admin)
  • Theme: Light and dark mode
  • Categories and products with multiple images and variants (size/color)
  • Shopping cart and orders with cash or bank transfer payment
  • Admin panel for orders, products, users, and settings

Categories & products

Screenshot: Category page — screenshots/02-categories.png

Features

  • Products by category with sort and filter (price, in stock, price range)
  • Product card: image, name, price, discount, quick view, add to cart
  • Breadcrumbs and JSON-LD for search engines

Product page

Screenshot: Product detail — screenshots/03-product.png

Features

  • Image gallery with multiple images
  • Product variants (size, color, etc.) with price and stock per variant
  • Customer reviews with star breakdown and “Verified purchase” badge
  • Related products and recently viewed
  • Quick view from the product grid without leaving the page

Cart & checkout

Screenshot: Cart — screenshots/04-cart.png

Cart

  • Items with quantity, price, and variant if any
  • Update quantity or remove item

Checkout

  • Shipping address and details form
  • Payment method: Cash or Bank transfer
  • Order summary and trust badges (editable from settings)

Customer account

Screenshot: Account dashboard — screenshots/05-account.png

  • Dashboard: orders summary and activity
  • My orders: list with details and tracking
  • Addresses: manage shipping addresses
  • Cart / Wishlist as configured

Admin panel — overview

Screenshot: Admin dashboard — screenshots/06-admin-dashboard.png

  • Widgets: orders today, orders this week, pending bank payments, unread contact messages, low stock products
  • Sidebar: Orders, Payments, Products, Categories, Users, Messages, Settings, Blog, Banners, Testimonials, Reviews, etc.

Admin panel — tables & sorting

Screenshot: Orders list with sorting — screenshots/07-admin-orders.png

Table features

  • Pagination with per-page choice (10, 20, 50, 100) — default 20
  • Sorting by clicking column headers (asc/desc)
  • Filter by status, number, etc. and CSV export for orders
  • Same pattern for: Orders, Products, Users, Messages, Payments, Categories, Reviews, Blog, Banners

Admin panel — Users & settings

Screenshot: Users list — screenshots/08-admin-users.png

Users

List all users with search, filter (customer/admin), pagination and sorting.

Settings

  • Site info, logo, language, editable labels
  • Contact links: WhatsApp, Instagram, Facebook, email, location, phones
  • Maintenance mode with return date and IP allowlist
  • Trust badges and custom code (Header/Footer) for marketing

Languages & theme

Screenshot: Language switch and dark mode — screenshots/09-lang-theme.png

  • Arabic (ar) and English (en) — switch from the front with preference saved
  • Menu and label text from translation files or settings (Labels)
  • Light / dark mode — toggle in the bar with system preference support

Extra features

  • Cookie consent — bar at bottom with accept option
  • Announcement bar and popup that can be dismissed
  • Blog / News — posts with scheduled publishing
  • Promo banners — date range and active/inactive from admin
  • Sitemap — /sitemap.xml for search engines
  • Maintenance mode — “We’ll be back soon” page with IP allowlist for admins
  • Static pages — Terms, Privacy, Shipping, Returns (content from settings)
